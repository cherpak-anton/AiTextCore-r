# Инвентаризация инструментов старого сайта

Источник: `AiTextCore-legacy/src` (старый сайт). Только чтение. Титульная страница (`/`) исключена: она самодостаточна и только переводит в рабочие окна.

Всего рабочих страниц: 35. `/welcome` и `/platform-admin` — не страницы (нет `page.tsx`).

Статусы в таблицах: **окно** — страница в общем шаблоне (шапка + панели), **без окна** — полноэкранная или авторизационная страница без шапки.

## D. Правила видимости (сводка)

- **Гость:** логотип, поиск, 📚, язык, вход, регистрация, справка. Без переключателя проекта и без 🗄️.
- **Вошедший без личного кабинета:** нет 🗄️.
- **Редакторы книги:** инструменты правки (меню книги, доступ, настройки, импорт, слайды, история, слияние, люди, хронология, источники).
- **Владелец кабинета:** счётчик использования, удалённые книги, хранилище, удаление книги без глав, имя кабинета.
- **Инструменты ИИ** (🤖, значки чатов, 🔤, 🎯, `LearnBadge`): только при работающем своём подключении ИИ и серверном тексте ИИ.
- **Системный доступ (`adminView`):** инструменты правки скрыты, показывается баннер.

## E. Что следует из инвентаризации

1. Постоянных инструментов 11 (раздел A). В новом проекте уже есть почти все; не хватает справки ❓, аватара с меню, настроек в модальном окне и перехода «Настройки» из меню пользователя.
2. Инструменты страницы книги повторяются на многих страницах (переключатель инструментов книги, `BookToolHeader`). Их стоит вынести в один набор.
3. Страницы без окна (вход, регистрация, урок, презентация, печать, слайды) — это инструменты. Вход и регистрация — поведенческие, показываются по состоянию клиента. Урок, презентация, печать и слайды открываются в рабочем окне (основная область или панель). Решение владельца, см. REQUIREMENTS 5.16.
